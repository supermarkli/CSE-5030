Lab 11: Ventus GPGPU Driver Lab
In this lab, you will use the Ventus GPGPU ISA Simulator (based on Spike) and its C++ driver library to study
GPGPU kernel programming on RISC-V. You will write vector computation kernels in RISC-V assembly, use
the driver API to manage device memory and kernel execution, and run your kernels on the simulator.

By the end of this lab, you will be able to:

    1. Build and configure the Ventus GPGPU ISA Simulator and its driver library
    2. Write and compile RISC-V assembly kernels with vector instructions for GPU-style execution
    3. Use the Ventus driver API to manage the full GPGPU compute pipeline
    4. Compare the Ventus GPGPU programming model with CUDA and OpenCL

Default environment configuration:

      Simulator: Ventus GPGPU ISA Simulator (Spike-based), cloned from GitHub
      Toolchain: RISC-V GNU Toolchain (riscv64-unknown-elf-*)
      Compiler: GCC 11 required (gcc-11, g++-11); GCC 13+ may produce build errors
      Driver library: libspike_driver.so, built from $SPIKE_SRC_DIR/gpgpu-testcase/driver/
      Work directory: $SPIKE_SRC_DIR/gpgpu-testcase/
      Install target: $SPIKE_SRC_DIR/spike/

   Note: After setting environment variables (SPIKE_SRC_DIR, SPIKE_TARGET_DIR), use the same
   terminal for the remaining commands or add them to your shell profile.
